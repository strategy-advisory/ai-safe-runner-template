# Contributing

Thanks for helping improve this template.

## Good Contributions

- clearer guardrails for risky actions
- better examples for dry-run and approval workflows
- portable tooling that does not assume a single provider
- documentation improvements based on real operational use

## Contribution Rules

- do not include real secrets or live credentials
- do not add bypass techniques for platform protections
- keep examples generic and safe for public repositories
- prefer small, reviewable changes with clear motivation

## Suggested First Contributions

- add a new example job request
- improve audit log fields
- add schema validation
- improve provider/account inventory guidance
